# Y2K Night

Ein von Y2K inspiriertes Theme für Claude Code in der Desktop-App, immer im Nacht-Modus: feines Lila-Raster, ein paar vierzackige Sterne, rosa Bubbles für deine Nachrichten, ruhige Karten für die Antworten und ein Pixel-Ladebalken in Lilac und Aqua.

*A Y2K-inspired dark theme for Claude Code in the desktop app: lilac grid, stars, pink user bubbles and a pixel loader. Loader labels are in German.*

## Installieren

**In der Desktop-App:** neben dem Eingabefeld auf **+**, dann **Plugins**, **Add marketplace** mit `desireedaydreams/y2k-night`, danach **Add plugin**.

**Im Terminal, in einer Claude-Code-Sitzung** (Nachfrage mit `y` bestätigen, dann den Bereich wählen):

```
/plugin install y2k-night --marketplace desireedaydreams/y2k-night
```

**Aus der Shell:**

```
claude plugin install y2k-night --marketplace desireedaydreams/y2k-night
```
